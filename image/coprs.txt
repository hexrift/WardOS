# Fedora COPR repositories the host enables before installing image/packages.txt
# (image/README.md, "COPRs"). One `owner/project` per line with the reason; blank lines
# and `#` comments are ignored. Every COPR here is part of the image's trust set: its
# packages are built by that COPR's owner, not by Fedora, and its repository file stays
# in the image so `wardos-install package` can layer from it. Keep the list short and
# each entry justified; when Fedora packages the thing, remove the entry. A COPR must
# build for the release the Containerfile pins (its fedora-<NN>-x86_64 chroot), which
# is what the "image packages" job proves.
#
# The Containerfile, image/check-packages.sh (CI: "image packages") and
# desktop/install.sh enable exactly this list, the same way.
#
# Empty on purpose: Fedora 44 is expected to carry the whole manifest.
