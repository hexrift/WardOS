# `snapshot-digest` fixture

A pinned, deterministic ~220-file tree (`tree/`, generated by `generate.py`,
fixed seed `150`) used to time `ward_snapshot` capture and digest work —
no bubblewrap, no sandbox, no daemon: this is a pure library-level
filesystem-walk-and-hash workload, so it runs anywhere the workspace builds.

This is a small, CI-sized fixture, not the 200k-file/1 GiB worktree from E-02
(`docs/experiments.md`) or the Btrfs hardware path — those need the reference
rig and are out of scope here (#150 items 2-5 note the CI-measurable subset
only). Regenerate with `python3 generate.py` if the fixture ever needs to
change; commit the resulting `tree/` so the fixture stays pinned across runs.
